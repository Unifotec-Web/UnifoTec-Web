# UNIFOTEC-WEB

A high-fidelity, multi-page technical website for UNIFOTEC-WEB featuring advanced interactive components, 3D animations, and a custom state-driven AI assistant.

## Features
- **Framework**: Next.js 15 (App Router) with React 19.
- **Styling**: Tailwind CSS.
- **Animations**: Framer Motion & Lenis Smooth Scroll.
- **AI Assistant**: State-driven floating assistant connected via webhooks.
- **Launch model**: Static-first public marketing site; no public CMS or admin service is included.
- **Responsive**: Fully optimized for mobile, tablet, and desktop viewports.

## Getting Started

### Frontend
```bash
npm install
npm run dev
```
